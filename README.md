A fully procedural drawing in pure Python stdlib: Mochi (orange) and Mimi (cream), two chubby kittens sitting cheek to cheek with big glossy amber and green eyes, blush cheeks, a tiny pink bow and forehead flowers, their paws together holding one pink heart, on a soft pastel background with polka dots and floating hearts. No model, no network, no image assets — every pixel is computed deterministically, so the program always writes the exact same PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
