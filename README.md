A fully procedural drawing in pure Python stdlib: Mochi, one chubby orange kitten filling the frame, with huge glossy amber eyes, blush cheeks, a tiny pink bow and a daisy, a chubby body with a cream belly, and both paws together holding one pink heart, on a soft pastel background with polka dots and floating hearts. No model, no network, no image assets — every pixel is computed deterministically, so the program always writes the exact same PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
